# 业务时序图

**版本：1.6｜范围：Claude plugin Skill 通过任务服务执行原业务步骤；上传采用云端签发、本地 PUT。**

原Skill步骤不变；调用方只保留Claude plugin Skill。Task/Processor与通用upload均为拟新增适配；查询和资源读取复用已有接口。本次提供Mermaid源码，不宣称已经通过渲染器验证。

## 普通生成

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant SK as Claude plugin Skill
    participant API as agent-sandbox API
    participant TR as Task与Runner
    participant P as YuE2Processor
    participant Y as YuE2运行环境
    participant F as 任务文件与结果记录

    U->>SK: 提供风格、歌词与生成要求
    SK->>SK: 按原Skill组织请求并保留请求键
    opt 请求包含外部ABC文件
        SK->>API: runner_upload(file_path, client_os)
        API-->>SK: 一次性 PUT URL 与本地 curl 命令
        SK->>API: 本地执行 curl，PUT /api/uploads/{token}
        API->>F: 按user_id和asset_id隔离、校验并登记
        API-->>SK: asset_id、sha256、size_bytes或上传错误
    end
    SK->>API: POST /runner/submit，yue2_task，operation=generate
    API->>API: 校验身份、字段、输入资产和任务就绪条件
    alt 参数或输入无效、环境未就绪
        API-->>SK: 真实4xx或503，不创建采样任务
        SK-->>U: 说明失败原因与所需修正
    else 请求有效
        API->>TR: 创建task_id并加入现有队列
        API-->>SK: task_id、info=pending、finished=false
        par 现有Runner执行
            TR->>P: YuE2Task固定绑定yue2_processor
            P->>F: 保存任务独立request.json，分配新输出目标
            P->>P: environment解析为/root/yue-env/bin/python
            P->>Y: 受控argv，generate --request绝对路径 --output新目录
            Note over P,Y: cwd独立配置；权重从/root/checkpoint加载
            Y-->>P: stdout、stderr与退出码
            alt 执行异常、超时或取消
                P->>Y: 终止并回收进程组
                P->>F: 保存日志和错误记录
                P-->>TR: info=error，finished=true
            else 原生执行返回
                P->>F: 检查音频、原生manifest、截断与乐谱检查结果
                alt 文件缺失、损坏或登记失败
                    P->>F: 保留已有原生结果与诊断
                    P-->>TR: info=error，delivery_status=failed
                else 可交付结果完成登记
                    P->>F: 登记result_source_name与实际文件元数据
                    P-->>TR: 完整结果快照，outcome=complete或needs_review
                    TR->>API: 既有进度回报，info=end，finished=true
                end
            end
        and 有限任务查询
            loop 未终态且少于12次且累计等待小于60秒
                SK->>API: GET /runner/result?task_id=...
                API-->>SK: 真实状态与已就绪资源清单
            end
        end
        alt 当前等待结束，任务仍未终态
            SK-->>U: 返回task_id和真实阶段，下次查询同一任务
        else 任务失败且无可取得结果
            SK-->>U: 返回失败阶段，不修改参数自动重采样
        else 清单包含可取得资源
            SK->>API: GET /runner/result_source，task_id与result_source_name
            API->>API: 校验主体及资源名称白名单
            API->>F: 只读已登记文件
            API-->>SK: 文件或明确读取错误
            loop 临时传输失败且重试少于3次
                SK->>API: 重取同一task_id和result_source_name
                API-->>SK: 同一文件或错误
            end
            alt 下载及完整性校验通过
                SK->>SK: 按原Skill检查结果、保留乐谱和请求、试听
                SK-->>U: 音频、实际产物与真实警告
            else 获取失败
                SK-->>U: 保留任务标识并说明获取错误，不重新采样
            end
        end
    end
```

## 转录与翻唱

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant SK as Claude plugin Skill
    participant API as agent-sandbox API
    participant TR as Task与Runner
    participant SP as SheetSage2Processor
    participant SS as SheetSage2运行环境
    participant YP as YuE2Processor
    participant Y as YuE2运行环境
    participant F as 任务文件与结果记录

    U->>SK: 提供原音频、目标风格与歌词
    SK->>API: runner_upload(file_path, client_os)
    API-->>SK: 一次性 PUT URL 与本地 curl 命令
    SK->>API: 本地执行 curl，PUT /api/uploads/{token}
    API->>F: 用户与asset_id隔离、校验完整性后登记
    alt 上传失败
        API-->>SK: 上传错误，不接受后续资产引用
        SK-->>U: 说明错误
    else 上传完成
        API-->>SK: asset_id、sha256、size_bytes
        SK->>API: POST /runner/submit，sheetsage2_task，transcribe
        API->>TR: 校验后入队
        API-->>SK: transcription_task_id
        TR->>SP: 固定绑定sheetsage2_processor
        SP->>SS: /root/sheetsage2-env/bin/python transcribe.py
        Note over SP,SS: 独立environment；音频绝对路径与全新output目录
        SS->>F: 加载SheetSage2及其匹配父模型，写ABC与报告
        SS-->>SP: 退出码、日志、原生结果
        SP->>SP: 回收进程，释放本阶段GPU资源
        SP-->>TR: 登记产物并报告end或error
        loop 未终态且少于12次且累计等待小于60秒
            SK->>API: GET /runner/result，transcription_task_id
            API-->>SK: 状态、warnings及资源清单
        end
        alt 未终态或无可用ABC
            SK-->>U: 返回当前状态或转录错误，停止后续生成
        else ABC可用
            SK->>API: GET /runner/result_source，task_id与score资源名
            API-->>SK: 已授权原谱及所需报告
            SK->>SK: 按原步骤检查、修正，保留原始转录
            opt 乐谱发生修改
                SK->>API: runner_upload(新ABC的file_path, client_os)
                API-->>SK: 一次性 PUT URL 与本地 curl 命令
                SK->>API: 本地 PUT /api/uploads/{token}
                API-->>SK: 新asset_id与完整性信息
            end
            SK->>API: POST /runner/submit，yue2_task，score_check
            API->>TR: 按原步骤执行inspect或strip_chords
            API-->>SK: check_task_id
            TR->>YP: abc_tools.py检查，无需加载GPU模型
            YP->>F: 保存检查报告及实际生成的新谱
            YP-->>TR: end或error与检查结果
            loop 未终态且少于12次且累计等待小于60秒
                SK->>API: GET /runner/result，check_task_id
                API-->>SK: 实际检查结果与清单
            end
            alt 未完成或乐谱条件不合格
                SK-->>U: 返回任务或检查差异，不进入生成
            else 乐谱条件合格
                SK->>API: POST /runner/submit，yue2_task，generate，cot=melody
                Note over SK,API: abc_source引用最终检查或去和弦后的实际资源
                API->>TR: 创建后续生成任务，不重跑转录
                API-->>SK: generation_task_id
                TR->>YP: 固定绑定yue2_processor
                YP->>Y: /root/yue-env/bin/python run_yue2.py generate
                Note over YP,Y: --request、--abc-file、--output为受控绝对路径
                Y->>F: 生成音频及原生元数据
                Y-->>YP: 退出码与日志
                YP->>YP: 回收进程
                YP-->>TR: 校验、登记并报告end或error
                loop 未终态且少于12次且累计等待小于60秒
                    SK->>API: GET /runner/result，generation_task_id
                    API-->>SK: 真实状态与资源清单
                end
                alt 音频可取得
                    SK->>API: GET /runner/result_source，task_id与音频资源名
                    API-->>SK: 原有音频文件或明确读取错误
                    SK->>SK: 按原步骤试听对比并保留来源记录
                    SK-->>U: 新音频、乐谱及检查说明
                else 仍在执行或失败
                    SK-->>U: 返回真实状态，不重复提交采样
                end
            end
        end
    end
```

## 编辑与再生成

```mermaid
sequenceDiagram
    autonumber
    actor U as 用户
    participant SK as Claude plugin Skill
    participant API as agent-sandbox API
    participant TR as Task与Runner
    participant P as YuE2Processor
    participant Y as YuE2运行环境
    participant F as 任务文件与结果记录

    U->>SK: 指定原作品、修改内容与保留约束
    SK->>API: GET /runner/result，source_task_id
    API-->>SK: 原任务真实清单或权限错误
    alt 缺少原谱或无权访问
        SK-->>U: 说明需先取得可编辑乐谱，停止当前编辑步骤
    else 来源可用
        SK->>API: GET /runner/result_source，原谱、原请求、原音频资源名
        API-->>SK: 已授权的原始产物
        SK->>SK: 按原步骤保留基线、定义约束、另写修改稿
        SK->>API: runner_upload(修改后ABC的file_path, client_os)
        API-->>SK: 一次性 PUT URL 与本地 curl 命令
        SK->>API: 本地 PUT /api/uploads/{token}
        API-->>SK: 新asset_id、sha256、size_bytes或上传错误
        SK->>API: POST /runner/submit，yue2_task，score_check
        API->>TR: 校验后按原步骤运行inspect或compare
        API-->>SK: check_task_id
        TR->>P: 固定绑定yue2_processor
        P->>Y: 目标解释器运行abc_tools.py，不加载GPU模型
        Y->>F: 保存音乐事件检查报告
        Y-->>P: 退出码和差异
        P-->>TR: 登记检查结果
        loop 未终态且少于12次且累计等待小于60秒
            SK->>API: GET /runner/result，check_task_id
            API-->>SK: 真实状态、检查结果与清单
        end
        alt 未完成或违反必须保留的约束
            SK-->>U: 返回任务状态或差异，停止自动再生成
        else 检查通过或已明确记录允许变化
            SK->>API: POST /runner/submit，yue2_task，generate，新请求及abc_source
            Note over SK,API: 引用修改稿，不覆盖原稿，不用旧latent冒充内容编辑
            API->>TR: 创建新的生成任务
            API-->>SK: new_task_id
            TR->>P: YuE2Task固定绑定yue2_processor
            P->>P: environment解析为/root/yue-env/bin/python
            P->>Y: generate --request新请求 --abc-file修改稿 --output新目录
            Y->>F: 保存新音频及原生结果
            Y-->>P: stdout、stderr及退出码
            alt 执行或文件检查失败
                P->>Y: 按需终止并回收进程组
                P-->>TR: info=error，保留原稿与诊断
            else 输出可交付
                P->>F: 登记新结果与来源关联
                P-->>TR: info=end，outcome=complete或needs_review
            end
            loop 未终态且少于12次且累计等待小于60秒
                SK->>API: GET /runner/result，new_task_id
                API-->>SK: 真实状态与资源清单
            end
            alt 结果可取得
                SK->>API: GET /runner/result_source，new_task_id与实际资源名
                API-->>SK: 新音频、乐谱与报告或读取错误
                loop 临时下载失败且重试少于3次
                    SK->>API: 重取同任务同资源，不新建采样
                    API-->>SK: 原有文件或错误
                end
                SK->>SK: 按原步骤对比完整歌曲和修改位置，保留每次尝试
                SK-->>U: 两版结果、修改稿和检查说明，获取失败时明确报告
            else 仍未完成或失败
                SK-->>U: 返回task_id与真实状态，不自动重采样
            end
        end
    end
```

## Runner四接口MCP封装

四个工具是原Runner能力的另一协议入口；Task与模型环境不变。前三图保留HTTP业务步骤，第四图说明同一能力的MCP文件传输。

```mermaid
sequenceDiagram
    autonumber
    actor SK as Claude plugin Skill
    participant MCP as agent-sandbox /mcp
    participant R as Runner共用业务函数
    participant T as 原Task与Runner
    participant P as 原模型Processor
    participant E as 对应模型环境
    participant F as 原资产与任务资源存储
    Note over MCP,R: MCP与保留的HTTP路由调用同一业务实现
    SK->>MCP: tools/list
    MCP-->>SK: runner_upload / runner_submit / runner_result / runner_result_source
    opt 本次任务需要输入文件
        SK->>MCP: runner_upload(file_path, client_os)
        Note over MCP: 只校验路径元数据，不读取客户端文件
        MCP-->>SK: 一次性、短效PUT URL与curl/curl.exe命令
        SK->>MCP: 本地执行命令，PUT /api/uploads/{token}
        MCP->>MCP: 消费token，有界写入owner-only临时文件
        MCP->>R: upload_input(认证主体, 临时文件)
        R->>R: 核对认证主体与资源归属
        break 上传失败、文件无效或无权限
            R-->>SK: 明确错误，不创建可用资产或模型任务
        end
        R->>F: 用户与asset_id隔离，完整写入并登记
        R-->>SK: 同一资产库的asset_id / sha256 / size_bytes
        Note over MCP,SK: PUT返回资产结果才算上传完成；旧URL不可重用
    end
    SK->>MCP: runner_submit(parameter, payload, idempotency_key)
    MCP->>R: submit_task(同主体, 同请求键, 原报文)
    alt 参数非法、越权或环境未就绪
        R-->>MCP: 原业务错误，不入队
        MCP-->>SK: isError=true与具体错误
    else 请求通过或命中同一请求键
        R->>T: 仅首次提交沿原队列创建任务
        R-->>MCP: 原task_id与接受状态
        MCP-->>SK: 结构化结果，不创建第二个任务ID
        par 原任务机制独立执行
            T->>P: 使用该Task原有固定绑定
            P->>E: 对应environment解释器执行原模型命令
            E-->>P: 输出文件、日志和退出码
            P->>F: 校验实际产物并登记result_source_name
            P-->>T: 既有状态与完整结果快照
            T->>R: 原进度和终态更新
        and 有限查询
            loop 未终态且查询少于12次且等待小于60秒
                SK->>MCP: runner_result(task_id)
                MCP->>R: get_task_result(同主体, task_id)
                R-->>MCP: 原状态与已就绪资源清单
                MCP-->>SK: 查询成功；模型失败保留在任务状态中
            end
        end
        alt 任务未完成或没有可读取产物
            SK->>SK: 保留同一task_id，结束本次等待
        else 资源就绪
            SK->>MCP: runner_result_source(task_id, result_source_name, mode)
            MCP->>R: open_task_resource(认证主体, 原资源标识)
            R->>F: 授权后只读原文件
            F-->>R: 文件描述、媒体类型、大小、SHA256
            R-->>MCP: 已授权文件及元数据
            alt 小文件且选择inline或auto
                MCP-->>SK: Base64原字节，delivery=inline，bytes_included=true
                SK->>SK: 解码、校验后保存；不变更文件格式
            else 大文件或选择link
                MCP-->>SK: 原result_source的resource_link，bytes_included=false
                SK->>R: 授权GET /runner/result_source，原task_id和资源名
                R-->>SK: 原文件流或明确错误
                SK->>SK: 校验实际文件大小与SHA256
            end
            loop 临时下载失败且重试少于3次
                SK->>R: 经相同工具或原HTTP路由重取同一资源
                R-->>SK: 同一文件或明确错误，不重新采样
            end
        end
    end
    Note over MCP,F: /api/uploads/{token}是传输适配路由，不是第五个Runner业务接口
```
